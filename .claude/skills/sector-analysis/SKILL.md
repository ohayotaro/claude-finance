# Sector Analysis

Sector analysis is T0/T1 for advisory work and T2 when it adds code, data pipelines, or strategy logic.

## Intake

- Record universe, sector taxonomy, benchmark, rebalance frequency, features, data source, and date range.
- Define whether analysis is descriptive, screener input, or strategy-design input.
- Require structured data inputs; image/chart interpretation is out of scope.

## Acceptance Checklist

- AC includes sector definition stability and reclassification handling.
- AC includes correlation, concentration, turnover, and transaction-cost considerations.
- AC includes point-in-time data constraints and survivorship-bias checks.
- AC includes source references and reproducible calculations.

## Delegation

Create the task brief and use the appropriate T0-T2 flow.
